# Readings

Notes and takeaways from articles, blog posts, talks, and books. Every source
gets sorted into one of the categories below, based on what kind of reaction
it produced.

| Category | Use it for |
|---|---|
| [Do This](do-this/index.md) | A practice or technique worth adopting |
| [Don't Do This](dont-do-this/index.md) | An anti-pattern or mistake to avoid |
| [Investigate](investigate/index.md) | Not sure yet — needs digging into |
| [Tasks For Me](tasks-for-me/index.md) | A concrete action item this reading triggered |
| [Why Don't We Do This](why-dont-we-do-this/index.md) | A gap between the source and current practice, worth questioning |
| [Keep This Note](keep-this-note/index.md) | A quote or explanation worth keeping, no action needed |
| [I Don't Get It](needs-more-attention/index.md) | Didn't click yet — needs another pass |

A single source can land in more than one category (e.g. a "Do This" and a
"Tasks For Me" entry from the same article) — just add it to each relevant
page.
