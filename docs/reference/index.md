# Reference

Two quick-lookup tools — for when you already sort of know what you're
looking for and just need the exact word for it, rather than reading a
page start to finish.

| Tool | Use it for |
|---|---|
| [Glossary](glossary.md) | Nouns — a term and its meaning, grouped by topic |
| [Phrasebook](phrasebook.md) | Verbs — the precise word for what code is *doing* (propagate, shadow, dispatch, ...) |
